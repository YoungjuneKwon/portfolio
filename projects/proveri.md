# Proveri — survey and statistics SaaS

**FastAPI · PostgreSQL · React + TypeScript · Paddle · GCP · Cloudflare**

https://proveri.ai — a survey platform that does not stop at charts. Respondents come in one end;
publication-ready inferential statistics come out the other.

## The gap it fills

Survey tools produce descriptive summaries. Statistical packages produce results but hide the
reasoning. Researchers and instructors end up exporting to SPSS, running tests by hand, and
pasting output back into a paper — and students learn the tool instead of the method. Proveri keeps
collection and analysis in one place and shows the analysis as a sequence a reader can follow.

## Engineering

**Backend.** FastAPI with SQLAlchemy 2.0 over PostgreSQL. OAuth via Authlib, JWT sessions,
Pydantic v2 throughout. Analysis runs on pandas and PyArrow.

**Statistics.** Inferential tests are computed by a house SDK that runs the Python scientific
stack under WebAssembly in the browser (see [Open Source](open-source.md)), so analysis happens
client-side and the published numerical behaviour is preserved rather than reimplemented.

**Data import.** Native SPSS `.sav` ingestion via `pyreadstat` and `pyspssio`, plus Excel — real
research data arrives in formats that tools written for web forms do not read.

**Frontend.** React with TanStack Router and Query, Tailwind, a TipTap-based rich editor for
survey content, drag-and-drop question ordering with dnd-kit, and virtualized tables for large
response sets.

**Billing.** Paddle as merchant of record for international sales — which pushes VAT, sales tax
registration, refunds, and chargeback handling onto the MoR rather than a one-person company —
alongside Apple In-App Purchase, with a credit and subscription model behind both.

**Infrastructure.** GCP Cloud Run, Cloud Storage, Pub/Sub, and Translate; Cloudflare tunnels and
DNS; AWS SES for delivery; Sentry for error tracking; GitHub Actions for CI. Feature work runs in
git worktrees, each wired to its own public preview subdomain and a cloned sandbox database.

**Quality.** Playwright end-to-end tests, and screenshot-driven documentation generated by
scripting the real application rather than maintaining images by hand.
